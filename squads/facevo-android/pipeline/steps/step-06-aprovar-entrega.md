# Step 06: Aprovar Entrega

Apresente integralmente `squads/facevo-android/output/revisao.md` ao usuario. Este checkpoint nao publica nem distribui o APK automaticamente.

## Se o Veredito for APPROVE

Solicite aprovacao final para encerrar o run. Destaque APK gerado somente se o revisor tiver confirmado caminho e comando de build bem-sucedido.

## Se o Veredito for CONDITIONAL APPROVE

Liste claramente as condicoes e pergunte se o usuario aceita os riscos residuais ou prefere retornar ao passo 2.

## Se o Veredito for ESCALATE

Mostre o problema repetido, as tres tentativas e as opcoes objetivas: alterar escopo, aceitar risco ou interromper.

## Registro

Apos a decisao, atualize `_memory/runs.md` com data, run ID, tema, output e resultado. Registre em `_memory/memories.md` apenas aprendizados reutilizaveis, nunca logs extensos ou afirmacoes nao verificadas.
